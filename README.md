# Kasoir Abbas — Senior Software Engineer Portfolio

Personal portfolio for **Kasoir Abbas** (`Senior Software Engineer`, Dubai, UAE), built with a low-glare **Warm Alabaster & Forest Teal** theme, custom system architecture cover banners, interactive career timeline, project topology inspector (Mermaid.js), and downloadable CV.

## Structure
```text
e:\Portfolio\
├── index.html                  # Main Portfolio Application Shell (All 6 Sections + Architecture Modal)
├── css/
│   └── styles.css              # Warm Alabaster & Forest Teal Theme & Component Styles
├── js/
│   ├── data.js                 # Complete CV Dataset, Experience, Projects, Skills & Education
│   └── app.js                  # Dynamic Rendering, Cover Switcher, Filtering, Clipboard & Mermaid Controller
└── assets/
    ├── profile.jpg             # Portrait Photo
    ├── Kasoir_Abbas_CV.pdf     # Downloadable Resume / CV
    └── cover-*.jpg             # Alternative Cover Artwork Assets
```

- **Hero & Custom System Cover Banner**: Features your portrait, exact CV summary, verified credentials, 4-column production metrics, and 4 switchable personal cover banners built directly from your CV facts.
- **Professional Experience Timeline**: Full breakdown of your roles at **Secure Parking (Dubai)**, **Socienta (Dubai)**, and **Syriatel Mobile Telecom (Damascus)**.
- **Production & Open-Source Projects**: Detailed showcases and interactive Mermaid.js architecture diagrams for **eView**, **ePay (.NET MAUI)**, **Hub (Kafka + MQTT + Agentic AI)**, **MT-URBAC & URBAC**, **Socienta SaaS Platform**, and **Spring Boot RBAC API**.
- **Skills Matrix, Education & Awards**: Interactive skill filtering, **M.Sc. in Web Science**, **B.Sc. in Software Engineering**, **ACPC 4th Place (Syria, 2016)**, and professional certifications.
- **Direct Contact & One-Click Copy**: Instant email/phone copy with toast confirmation and direct CV PDF download.

## Deployment (Vercel or GitHub Pages)
- **Vercel (`kasoir.vercel.app`)**: Import the repository into Vercel with Framework Preset set to `Other` (Static). It deploys immediately with zero build steps.
- **GitHub Pages (`kasoir.github.io`)**: Push all files to the `main` branch of `kasoir/kasoir.github.io` and enable GitHub Pages from `main` / `/ (root)`.
